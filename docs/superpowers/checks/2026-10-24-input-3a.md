## Fresh-game live procedure

1. Finish review and remaining automated checks before this gate. Exit the previous game and old OSR host. Start a fresh Deadlock session in Hideout with the existing drawing layer and `UW_SPIKE_CAPTURE=win32` in its launch environment. The layer must draw only: do not launch the old spike input injector or collector. Keep the game foreground.
2. Record the commit, Deadlock ClientVersion, Proton path/version, desktop/session type, GPU, resolution and DPI. Do not reuse observations from earlier phases.
3. Start the dedicated receiver, keeping its PID and log:

```sh
cd /home/buga/.codex/worktrees/d200/underwolf
uw_input_logdir="$PWD/target/input-3a-live-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$uw_input_logdir"
git rev-parse HEAD > "$uw_input_logdir/revision.txt"
UW_SPIKE_CAPTURE=win32 spikes/osr-host/node_modules/electron/dist/electron \
  --ozone-platform=x11 spikes/osr-host --capture production \
  --input-command "$PWD/scripts/input-3a-launch.sh" \
  > "$uw_input_logdir/receiver.log" 2>&1 &
uw_input_receiver_pid=$!
printf '%s\n' "$uw_input_receiver_pid" > "$uw_input_logdir/receiver.pid"
```

`UW_INPUT_PID`, `UW_INPUT_EXE` and `UW_INPUT_PROTON` optionally pin the launcher's game discovery. The receiver log prints its launcher PID. The test surface shows actual state, keys, text, five button labels and wheels. It does not draw a second cursor or call any spike capture entry point.

4. Observe each scenario below. For a stall, stop renderer consumption with `kill -USR1 "$uw_input_receiver_pid"`; allow at least one second and check game input returns. Resume with `kill -USR2 "$uw_input_receiver_pid"`. Resuming must not recapture; use a fresh Ctrl+Tab press.
5. To test helper loss, take the launcher PID printed in the log. Inspect only its children with `ps -o pid=,args= --ppid "$uw_input_launcher_pid"`, select the displayed `uw-helper64.exe` PID, then `kill -KILL "$uw_input_helper_pid"`. Verify `helper_restarted`, a new epoch and inactive capture. Make an explicit fresh Ctrl+Tab request afterward.
6. Stop with `kill -TERM "$uw_input_receiver_pid"`. Its owned launcher closes the helper; the local lease releases capture. Wait for the game to process its UI messages before assessing cursor restoration. Keep the logs on any failure. The pinned module remains loaded until the game exits.
