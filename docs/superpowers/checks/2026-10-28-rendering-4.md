## Task 3: Native shared frame channel

Twenty native tests passed: real shared pages and size seals, checked row copies,
immutable claimed pixels, scoped descriptor transfer, bounded partial-I/O failure,
peer/incarnation verification, active-client preservation and fresh reconnect
sessions. Separate subprocesses verified lock contention, explicit consumption,
a producer killed halfway through a write, and 100-generation FD/mapping cleanup.
One ignored test is solely the subprocess actor entry, not an untested product
acceptance case. Strict Clippy (including unsafe comments) and the Windows
all-target check passed; the workspace passed **744 / 0 / 93 ignored**.

Native open/descriptor export are explicitly unsafe because headers cannot prove
arbitrary pthread bytes were initialized. Budget-aware constructors retain charges
while mappings remain referenced. Private endpoint ownership uses an advisory lock
and inode-checked cleanup; one small lock file persists per process incarnation
so waiters cannot acquire a newly-created competing lock. These are recorded
execution rulings; shared-page tests do not prove actual GPU behavior.
