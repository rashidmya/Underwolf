## Task 1: Electron image contract

Twelve Node tests failed against the source scaffold and then passed with the
implementation. They cover disjoint patches, transparent clearing, retained and
owned modes, bounds/length validation, partial bitmap placement and disposal.
Actual Electron **44.9.1** paint checks passed at scales **1 and 1.5** in both
explicit software/Xvfb and the normal display with GPU compositing enabled.
Complete BGRA snapshots remained stable across later changes, and physical-pixel
cropping matched independent reference pixels. Select `retained-full` for these
qualified environments; the owned-backing fallback remains implemented/tested.
GC was not exposed, so no forced-GC/lifetime-pressure result is claimed.

The non-unit-scale fixture initially upscaled a low-resolution canvas, producing
filtered edge colors. A DPR-sized canvas backing store resolved this; production
pixel extraction was unchanged. The runner now controls `window-all-closed`, so
closing an isolated scenario cannot exit before the report is durable. An Xvfb
GPU-info rejection is retained as environment metadata rather than a fabricated
GPU result. The normal-display log includes a nonfatal GBM loader warning;
Electron still reports GPU compositing enabled and passed the pixel checks.

Raw reports: `target/render-4/image-contract/{software,display}/qualification.json`.
